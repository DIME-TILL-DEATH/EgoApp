# EgoApp

EgoApp is AMT's desktop application for **AMT EgoGig4** users. It helps create and edit playlists, organize media, and prepare content on an SD card or in a local folder for later transfer to the device.

## Features
- Create and edit playlists.
- Work with SD cards and local folders.
- Prepare audio(format conversion).
- Preview audio.

## Target platforms

| Platform | Qt | Minimum target OS |
|---|---:|---|
| macOS | 6.7 | macOS 11 |
| Windows | 6.11/6.12 | Windows 10 1809 |
| Linux | 6.11/6.12 | Ubuntu 22.04, 24.04; Debian 12 |

These are targets, not proof of runtime validation. See [PLATFORM_SUPPORT.md](docs/PLATFORM_SUPPORT.md).
